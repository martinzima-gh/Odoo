# AG-000 Název úkolu

Šablona zadání pro Antigravity (druhý vývojář). Pravidla jsou v `.agents/rules/`, role v `CLAUDE.md` (Role agentů).
Soubor zkopíruj jako `AG-<číslo>-<název>.md`. Zadání píše Claude nebo uživatel; sekci Výsledek doplní Antigravity.

## Zadání

| Položka | Hodnota |
|---|---|
| Zóna | zelená / oranžová / červená |
| Výchozí větev | např. `feature/nav-prototyp` |
| Větev úkolu | `ag/AG-000-nazev` |
| Zadal, dne | |
| Navazuje na | krok akčního plánu revize, rozhodnutí v deníku |

**Cíl:** co má být po dokončení jinak a proč.

**Rozsah souborů:** které soubory se smějí měnit. Mimo ně nic.

**Mimo rozsah:** co se dělat nemá.

**Kritéria přijetí:** ověřitelné body (co uvidí uživatel, jaký test projde).

**Schválený plán** (jen oranžová a červená zóna): návrh od Clauda, u červené zóny se schválením uživatele a datem.
